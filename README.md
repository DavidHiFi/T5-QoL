> [!NOTE]
> **Development has not started yet.** This repository is a placeholder for the T5 QoL mod. [T6-QoL](https://github.com/DavidHiFi/T6-QoL) is the current focus; work on Black Ops begins once that is finished.

Part of the [Plutonium Quality Of Life Series](https://github.com/DavidHiFi/Plutonium-QoL-Series).

## Managing your Black Ops mods

You do not have to wait for this mod to get some use out of the series' tooling. The [**Quality of Life Series mod manager**](https://github.com/DavidHiFi/QualityOfLifeSeries) already handles Black Ops: it lists every mod in your Plutonium folder with its size and location, installs new ones from a file or from a browsable list, removes the ones you are done with, and launches the game online or in LAN.

[Download it](https://github.com/DavidHiFi/QualityOfLifeSeries/releases/latest) - setup or portable, Windows 10 or 11. It will install this mod too, once there is one.
